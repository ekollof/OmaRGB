Wiki

These pages live in the repository under docs/wiki, next to the code they describe. The database in share/devices.toml is the list of named devices. This wiki is the explanation.

  • Devices. Supported hardware, OpenRGB keyboards as a class, and the devices that have been painted on a real machine.
  • Extending OmaRGB. A new database row, a new engine, the colour rules, and the checks to run.
  • From Omarchy. Which mainline painters OmaRGB replaces, which checks it keeps, and where it refuses to follow Omarchy.

A new device or engine still starts as a GitHub issue. The steps are in CONTRIBUTE.md.
