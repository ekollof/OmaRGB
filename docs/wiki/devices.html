Devices

OmaRGB paints a device when a row in share/devices.toml matches it. One class does not need a row: an OpenRGB keyboard with a per-LED mode and more than one LED. Anything else the server can see stays dark.

Supported

A gradient uses the theme's colour stops. A solid device uses one stop. OpenRGB sets that mode's full brightness when the mode has a brightness range.

Framework Laptop 16 keyboard USB 32ac:0012, or DMI Framework:*Laptop 16* framework16 One colour, through qmk_hid
ASUS ROG keyboard DMI ASUSTeK COMPUTER INC.:*ROG* asus_rog One colour, through asusctl aura static
Home Assistant lights A lamp named in ~/.config/hass.cfg whose entity id matches light.* homeassistant One colour, and only when the lamp is already on. The default stop is the warmest

The bar can turn any of these off, or pin a gradient device to one colour. That choice is ~/.config/omargb/behaviour.json.

Tested

Supported is what the database will match. Tested is what has been painted on one machine. Framework and ASUS are supported by the same checks Omarchy uses, and have not been run here.

DeviceWhat was seen
Sound BlasterX Vanguard K08 USB 041e:3126. The gradient runs side to side. Only the LED bytes in the lighting map are written.
Razer BlackWidow V3 USB 1532:024e. OpenRGB reports a keyboard, Direct mode, 132 LEDs, and a 22 by 6 matrix. The gradient runs left to right.
Logitech G513 USB 046d:c33c. OpenRGB reports a keyboard, Direct mode, 107 LEDs, and a 21 by 6 matrix. No database row. The gradient runs left to right.
Razer Basilisk V3 USB 1532:0099. Direct mode, a logo, a scroll wheel, and a linear strip. The gradient follows that LED list.
Corsair Vengeance RGB Pro DDR4 Four sticks. Each has Direct mode and 10 LEDs. The gradient follows the LED list.
Corsair Commander PRO USB 1b1c:0c10. OpenLinkHub paints one colour. OpenRGB sees the hub with no LED list, so the fallback is Static mode.
MSI X470 GAMING PLUS MAX One Direct LED. It stays a single theme colour.
Home Assistant Lamps listed in hass.cfg take one theme colour when they are already on. Lamps that are off are left off.
